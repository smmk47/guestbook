# Guestbook – Containers, Docker and Kubernetes Final Project

**Project name:** Guestbook application on Kubernetes (build, push, deploy, autoscale, rolling update and rollback)

A simple Go guestbook web application (`v1/guestbook`) packaged with a multi-stage Dockerfile, deployed to
Kubernetes with `deployment.yml`, autoscaled with a Horizontal Pod Autoscaler, then updated (v2) with a rolling
update and rolled back.
